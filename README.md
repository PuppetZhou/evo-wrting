# evo-wrting

Date: 2026-10-31
状态：第一版；通用基础架构已建立，具体应用随新项目验证和改进。

仓库：[PuppetZhou/evo-wrting](https://github.com/PuppetZhou/evo-wrting)。名称按仓库拼写保留为 `evo-wrting`。

本 skill 提供写作基本功、可调整的组织模式、资料索引和记忆方法。每遇到一篇新论文，agent 在论文自己的工作区调研、积累素材、试写并根据反馈改进；单篇文章的事实与偏好不成为 skill 的默认规则。

## 通用部分

| 文件 | 用途 |
| --- | --- |
| [SKILL.md](SKILL.md) | 简短执行入口和按问题读取的路由 |
| [写作基本功](references/writing-foundations.md) | 文章类型、章节任务、段落模式、表达和改稿判断；主要面向生物医学，兼顾共性 |
| [来源与学习范围](references/foundations-sources.md) | 经典论文、课程、作者文字及报告规范的出处；明确读到什么、尚未读到什么 |
| [工作记忆与论据](references/memory-and-evidence.md) | 新文章的最小工作区、压缩后恢复、引用积累与反馈保存 |

学习指导、报告规范、期刊要求分别标记。基本功中的模式可以调整，不能代替真实证据、目标体裁的范文或作者意图。

## 每篇新文章的工作区

默认在论文根目录建立以下目录；已有同职责文件时复用，不在 skill 内保存文章素材。

```text
<paper-root>/.scientific-writing/
├── brief.md             读者、贡献类型、研究设计、目标稿件与作者偏好
├── state.md             当前任务、关键决定、证据入口、下一步
└── materials/
    ├── index.md         主题、稳定 ID、用途和来源核验状态
    └── <topic>.md       有实际素材才创建：原句、论据、转述、应用及反馈
```

原始文献、正文和数据依据优先链接原位。关键发现随工作保存；恢复先读短状态，再按主题读细节。跨文章素材可进入作者指定的独立共享库，skill 仅在基础方法需要改进时更新。

## 使用

> 阅读此仓库的 `SKILL.md`。本篇文章位于【论文根目录】，素材与工作记忆保存在【指定目录；未指定则使用默认位置】，当前任务是【学习/调研/写作/修改】。请建立或恢复该文章的工作记忆，按文章类型和当前段落任务调用基础知识，并保存有用素材与反馈。

仓库提供 skill 源码，直接指定 `SKILL.md` 即可开展项目工作；本次未安装到本地技能目录。默认无需通读整份基本功或全部来源；按入口定位相应小节即可。论文原文、手稿和项目素材库保存在作者指定的独立目录，不随本仓库发布。
