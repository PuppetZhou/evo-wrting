# 工作记忆与论据：最小记录约定

Date: 2026-10-30

## 新项目与恢复入口

工作区默认在 `<paper-root>/.scientific-writing/`，与 skill 分开；复用已有的同职责记录。新项目只建立三个简短文件，有实际内容再扩展：

- `brief.md`：读者、论文贡献类型与研究设计、活动稿及证据位置、语言和作者偏好。未知项明确待定。
- `state.md`：当前任务、已完成内容、关键决定的短摘要、材料指针、下一步。
- `materials/index.md`：材料 ID、主题、用途、出处状态和条目链接。主题文件按需创建。


`state.md` 记录：当前任务与范围；目标稿件/段落及可用版本定位；已完成到哪里；重要决定及理由的短摘要；待解决问题和下一步；相关素材 ID/链接。决定区分作者明确要求与 agent 建议。

读完状态页后，只读取本轮涉及的 brief、主题素材和活动稿。文件状态变化时核对相关部分；有冲突就回到原始决定或证据，不让旧摘要覆盖新材料。没有依据的细节记为未知。

发现关键材料或收到重要反馈就写入对应文件，再更新入口；切换段落和结束工作时检查下一次能否直接接上。状态页可以重写为最新摘要，原句、限定、取舍理由与证据链接留在主题记录或原有文档中，不反复压缩成无出处的概括。

## 一条素材需要保存什么

主题文件按需要建立，例如 `materials/background.md`；一个文件可容纳多条素材。先查索引与原文定位去重，复用已有参考文献管理记录或文献键。下面仅示意格式，不是真实论据：

```text
### E001 | 主题 / English keyword | 类别：论据 | 日期：…
来源：作者—年份、标题、DOI/稳定链接或文献键；本地原文路径
定位与读取：页码/小节/段首；读到全文片段、摘要还是二手转引；核验状态
原文依据：必要的准确短摘录，或既有原文的精确指针；保留上下文限定
可转述内容：忠实概括；区分研究结果、作者解释、理论观点或展望
适用边界：对象、时间、条件、反证/限制；这一来源不能支撑什么
使用记录：拟用/已用/弃用；稿件路径与句/段定位；引用待补/已核；反馈理由
```

表达素材用 `L001` 等稳定 ID，保留原句/搭配、来源定位、写作作用和适用条件；术语可同页记录含义与易混词。作者反馈用 `D001` 等 ID，写明原话或转述、作用范围与决定理由。已有明确 ID 时沿用，不另建编号体系。无关字段可省，未知字段标未知。

索引每条只留 **ID、主题/检索词、一句用途、来源核验状态、文件链接/锚点**。中英文别名有助找回材料；规模小可合并索引行，变长再拆主题。一次采集不用创建多种卡片，全文保存在原位。

## 论据与引用的使用

- 可以借助文献中已有的理论、观察和观点支持自己的论述。保留来源归属，用自己的话准确转述；研究对象、否定、概率和条件等含义不能随润色改变。
- 收录时区分原文摘录、转述草案与 agent 推断。写入正文时检查引用是否支持该句的实际范围；复合论断需要时对应多条材料，不能用一个引文包办整句。
- 现状、趋势与数字保存来源时间和范围，应用为“当前”事实前判断是否需要更新；未来展望标明是来源作者的判断，不升级为既定事实。
- 文献 A 转述文献 B 时，记录实际读过谁。需要以 B 为直接依据时再读取 B；未读时保持转引身份，不补造书目字段或核验结果。
- 首稿暂不编排正式引文时，在素材使用记录中保存“稿件段落/句子定位 → 素材 ID → 来源”。后续修改句子时同步映射；定稿据此核对归属、支持范围与引用编号。

已有采集记录且来源与用途未变时直接复用；新用途超出已读范围、材料冲突或时效变化时再定向核实。引用核验与作者是否认可文字分别记录。

## 更新经验

有用材料先留在本项目；需要跨文章复用时，再整理到作者指定的独立共享库并保留条件、例外与应用链接。经验被反例推翻就修正；基础方法的变更才进入 skill，不自动把项目反馈叠加为通用规则。
