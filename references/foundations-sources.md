# 写作基本功：来源与学习范围

Date: 2026-10-30
用途：为[写作基本功](writing-foundations.md)提供可核查的出处和补读入口。这里保存定向调研结果，不保存单篇手稿经验，也不声称完成系统综述或全部课程。

## 研究问题与取舍

1. 哪些读者、论证和表达原则可以跨文章复用？
2. 生物医学不同贡献类型、研究设计和章节承担哪些不同任务？
3. 如何将这些指导转成 agent 按需读取、可修正的段落模式，而不形成固定文风？

检索覆盖经典修辞指导、作者与大学教学材料、生物医学报告规范三个方向，并追查用户课程的作者来源。优先采用原论文、作者公开文字、官方课程资料、出版商样章及规范制定方。网站摘要、课程目录和二手纪要只支持实际读到的范围；无全文不推断细节。以下阅读包括并行调研后合并核查的结果。

## 综合与未完成部分

三组来源共同支持：按读者和任务组织内容，保留可追溯证据，按具体问题修改。它们覆盖的是不同层次：Gopen–Swan 偏重句子如何被解释，Mensh–Kording 与 MIT 偏重结构，报告规范偏重信息完整性。因此基本功将这些层次分别调用，不把所有建议合成一张强制检查表。

课程原讲、样章和规范均按实际范围使用；没有给某一教学体系作因果有效性排名。尚待补充的是用户指定合集的完整内容；新文章需要的专门体裁、研究设计或期刊要求应在该文章工作区继续调研，不在 skill 中预建所有分支。
